Remove Matched Albums
======================

Overview
---------

This plugin allows the user to remove completely matched and saved albums from the album pane.

The plugin is based on the Picard v2 "Remove Perfect Albums" plugin by ichneumon and hrglgrmpf. The original Picard 2 plugin code is available on GitHub at "`Remove Perfect Albums <https://github.com/metabrainz/picard-plugins/blob/2.0/plugins/remove_perfect_albums/remove_perfect_albums.py>`_".


What it Does
-------------

This plugin provides an action under Picard's main menu. When :menuselection:`Plugin Tools --> Remove matched albums` is clicked, each of the albums listed in the Albums pane is examined for possible removal. If the album is complete with all tracks matched to an audio file and all of the files have been saved, then the album is removed from the list.
